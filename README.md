# 跳一跳 · Jump Jump（网页版）

一个仿微信「跳一跳」的单文件网页小游戏，双击即玩，无需安装任何依赖。

## 怎么玩

- **直接双击 `index.html`** 用浏览器打开即可；
- 或者起一个本地服务：`python3 -m http.server 8130`，然后访问 <http://localhost:8130>。

## 操作

| 平台 | 蓄力           | 起跳 |
| -- | ------------ | -- |
| 电脑 | 按住鼠标左键 / 空格键 | 松开 |
| 手机 | 按住屏幕         | 松开 |

按住时间越长，跳得越远。松手后棋子沿对角线方向跳向下一个方块。

## 计分规则

- 落在方块上（任意位置）：**+1**
- 落在方块**中心圆圈**内：**完美**，+2、+4、+6…（连续完美分数翻倍递增）
- 落到方块外：坠落，游戏结束
- 最高分自动保存在浏览器（localStorage），右上角 🔊 可静音

## 实现说明

- 全部代码在 `index.html` 一个文件里：Canvas 2D 手写 2:1 轴测投影（2.5D 效果），无任何外部资源与依赖；
- 音效用 WebAudio 实时合成（跳跃 / 落地 / 完美 / 坠落）；
- 方块随机生成（方体 / 圆柱），每一块的横向位置与棋子对齐，保证任何落点之后下一跳都可达；
- 落地有一整套打击感动效：棋子压扁弹性回弹、方块受击下沉回弹、扬起灰尘粒子；落在中心时额外触发金色扩散圈 + 白色闪环 + 金色火花；
- 落点判定带边缘容差；连续完美有金色扩散圈与连击提示；
- `window.__jump()` 是一个调试钩子，可在控制台查看当前状态（棋子坐标、平台布局、得分等）。
